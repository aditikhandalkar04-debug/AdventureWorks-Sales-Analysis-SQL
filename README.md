# AdventureWorks-Sales-Analysis-SQL
# AdventureWorks Sales Analysis using SQL

##  Project Overview
This project analyzes AdventureWorks sales data from 2015 to 2017 using SQL and PostgreSQL. The goal is to explore sales trends, product performance, customer purchasing behavior, and product returns to generate useful business insights.

##  Business Questions
- What is the total order quantity for each year?
- What is the total sales amount from 2015 to 2017?
- Which product categories generate the highest sales?
- What are the top 10 products by sales?
- Who are the top 10 customers by sales?
- How can customers be segmented based on total sales?
- Which countries generate the highest sales?
- Which customers purchased the highest total quantity?
- Which products have the highest return quantities?
- Which product categories have the highest return rates?
- What are the monthly sales trends?

##  Tools Used
- PostgreSQL
- pgAdmin
- SQL

##  SQL Skills Demonstrated
- SELECT, WHERE, ORDER BY and LIMIT
- INNER JOIN and LEFT JOIN
- Aggregate functions: SUM, COUNT and AVG
- GROUP BY and HAVING
- UNION ALL
- Common Table Expressions (CTEs)
- Subqueries
- CASE WHEN for customer segmentation
- Date functions and monthly sales analysis

##  Analysis Areas
- Yearly sales and order quantity
- Product and category performance
- Top customers and customer segmentation
- Country-wise sales analysis
- Monthly sales trends
- Product returns and return rates

##  Project Files
- `AdventureWorks_Sales_Analysis.sql` — SQL queries used for the analysis.
- AdventureWorks CSV files — source datasets, if included in the repository.

##  Note
Sales amount calculations depend on the columns available in the dataset and the formula used in the SQL queries. If sales are estimated using product price multiplied by order quantity, the results should be interpreted as calculated sales rather than verified transaction revenue.
